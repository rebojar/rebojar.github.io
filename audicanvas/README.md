# AUDICANVAS — espelho público da demo

Esta pasta contém somente a demonstração experimental que aparece em https://rebojar.github.io/audicanvas/. A fonte do projeto é o repositório privado `rebojar/audicanvas`; este espelho foi gerado a partir do commit `8bec3c1f10d5d241f3dc37a5546b34dfe9d11c7b` por `scripts/build-demo.mjs`. Não edite o espelho como segunda fonte.

O JavaScript necessário para executar a demo é público por ser entregue ao navegador. O pacote não inclui documentos de coordenação, biblioteca de gravações, arquivos locais ou analytics remoto. Os sons atuais são sintéticos e provisórios. Os testes perceptuais dos Gates 1 e 3 seguem pendentes; a demo não deve ser apresentada como produto final.
