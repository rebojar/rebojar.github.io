# AUDICANVAS — espelho público da demo

Esta pasta contém somente a demonstração experimental que aparece em https://rebojar.github.io/audicanvas/. A fonte do projeto é o repositório privado `rebojar/audicanvas`; este espelho foi gerado a partir do commit `a140ca7` por `scripts/build-demo.mjs`. Não edite o espelho como segunda fonte.

O JavaScript necessário para executar a demo é público por ser entregue ao navegador. O pacote não inclui documentos de coordenação, biblioteca de gravações, arquivos locais ou analytics remoto. Os sons atuais são sintéticos e provisórios. Arquivos de estilo e módulos têm versão por conteúdo para evitar JavaScript antigo em cache. A interface permite ocultar a trajetória visual, isola os ensaios e mostra o tempo da caminhada. A cena de asfalto usa uma configuração JSON com flor seca, folha e pedrinha, e permite alterar a frequência dos contatos. Gates 1 e 3 receberam aprovação perceptual; Gate 4 ainda aguarda escuta humana. A demo não é produto final.
