# AUDICANVAS — espelho público da demo

Esta pasta contém somente a demonstração experimental que aparece em https://rebojar.github.io/audicanvas/. A fonte do projeto é o repositório privado `rebojar/audicanvas`; este espelho foi gerado a partir do commit `32dcc5c` por `scripts/build-demo.mjs`. Não edite o espelho como segunda fonte.

O JavaScript necessário para executar a demo é público por ser entregue ao navegador. O pacote não inclui documentos de coordenação, biblioteca de gravações, arquivos locais ou analytics remoto. Os sons atuais são sintéticos e provisórios. Arquivos de estilo e módulos têm versão por conteúdo para evitar JavaScript antigo em cache. A interface permite ocultar a trajetória visual, isola os ensaios e mostra o tempo da caminhada. O Gate 1 recebeu aprovação perceptual para a variante rica; o Gate 3 requer novo teste de dois minutos após relato de parada prematura. A demo não é produto final.
