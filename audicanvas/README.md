# AUDICANVAS — espelho público da demo

Esta pasta contém somente a demonstração experimental que aparece em https://rebojar.github.io/audicanvas/. A fonte do projeto é o repositório privado `rebojar/audicanvas`; este espelho foi gerado a partir do commit `c3621e3` por `scripts/build-demo.mjs`. Não edite o espelho como segunda fonte.

O JavaScript necessário para executar a demo é público por ser entregue ao navegador. O pacote não inclui documentos de coordenação, biblioteca de gravações, arquivos locais ou analytics remoto. Os sons atuais são sintéticos e provisórios. A interface permite ocultar a trajetória visual e impede que os testes de passagem e passos soem juntos. Os testes perceptuais dos Gates 1 e 3 seguem pendentes; a demo não deve ser apresentada como produto final.
