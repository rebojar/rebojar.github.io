# Widget Placa

Placa suspensa do Rebojar para reunir botões de apoio ou outros botões escolhidos pela pessoa usuária.

## Funcionamento

- A placa usa a madeira azul da Estante e duas cordas laranjas presas ao topo.
- GitHub Sponsors, Ko-fi e Apoia.se aparecem por padrão.
- O botão “+”, ao lado dos controles de som, permite mostrar ou esconder cada apoio.
- “Seu próprio botão” permite guardar um nome e um endereço `http` ou `https`.
- As escolhas ficam no `localStorage` do navegador.

## Incorporação

`index.html?embed=1` mostra somente as cordas, a placa e seus botões. O cabeçalho, os controles de som, o menu de edição e a instrução ficam na página própria do widget.
