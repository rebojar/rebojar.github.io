# Widget da Porta

Widget independente que representa uma passagem para futuros espaços do Rebojar.

- Dois cliques na maçaneta abrem ou fecham a porta.
- Arrastar a maçaneta como um giro também abre ou fecha.
- Atrás da porta há uma sala branca com passagens identificadas para Garatujas, Lab Visual, Audio Canvas e Galeria, além de uma passagem futura.
- Ao escolher uma passagem, a porta colorida cresce até ocupar toda a janela antes de abrir o destino.
- No portal, o widget ocupa a passagem entre a estante e a área de apoio no desktop. Ele não faz parte da estante.

Estado: `candidato local`.
